# WMSTrack Pro

A warehouse management tool for tracking inventory and stock movements — built to replace manual spreadsheet tracking with something faster and less error-prone.

## What it does

- Tracks inbound and outbound stock movements
- Keeps a live view of current inventory levels
- Built from real warehouse operations experience (3PL, JAFZA) — designed around how stock actually moves on the floor, not a generic template

## Why I built it

Manual stock tracking in spreadsheets doesn't scale and breaks easily when multiple people are updating the same file. This is my attempt at a lightweight, purpose-built alternative.

## Tech stack

JavaScript

## Background

Built by a Logistics Coordinator (not a software engineer) — reflects hands-on warehouse ops knowledge applied to solving a real operational problem.
